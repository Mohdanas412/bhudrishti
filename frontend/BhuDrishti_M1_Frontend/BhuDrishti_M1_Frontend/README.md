# BhuDrishti - M1 Frontend Starter

This folder contains the M1 dashboard frontend starter.

## Structure

frontend/src/
- components/
  - Header.jsx
  - Sidebar.jsx
  - StatCard.jsx
  - DashboardLayout.jsx
- pages/
  - Dashboard.jsx
- mock/
  - dashboard.json
- App.jsx
- main.jsx
- index.css

## Install

Copy these files into your existing BhuDrishti frontend project.

From the `frontend` folder run:

```bash
npm install
npm run dev
```

This starter uses mock JSON data and does not require the backend.

## M1 ownership

M1 focuses on the product/dashboard UI in:
- frontend/src/pages
- frontend/src/components
- frontend/src/mock

M2 can later replace the GIS placeholder with the real map module.
